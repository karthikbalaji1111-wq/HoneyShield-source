# API reference (summary)

OpenAPI is generated by FastAPI and exposed at `/docs` outside production (or with
`EXPOSE_API_DOCS=true`). Errors are `{"detail": "...", "request_id": "..."}`; validation errors
never echo input. Roles: SA = SYSTEM_ADMIN, TA = TENANT_ADMIN, TU = TENANT_USER.

## Control host

| Method & path | Role | Notes |
|---|---|---|
| POST `/auth/login` | – | `{email,password,otp?}` → `{access_token}`; 30/min/IP. MFA accounts without `otp` → 401 `MFA code required` |
| GET `/auth/me` | any (incl. MFA-pending) | identity, role, tenant slug, `mfa_enabled`, `mfa_required`, `mfa_enrollment_required` |
| POST `/auth/mfa/setup` | any (incl. MFA-pending) | `{current_password}` → `{secret, otpauth_uri, algorithm, digits, period}` |
| POST `/auth/mfa/enable` | any (incl. MFA-pending) | `{code}` → `{access_token (MFA session), recovery_codes[10]}` (shown once) |
| POST `/auth/mfa/recovery-codes` | MFA session | `{code}` (TOTP only) → new `recovery_codes`; old ones stop working |
| POST `/auth/mfa/disable` | MFA session | `{current_password, code}`; 403 if the role requires MFA; revokes all tokens |
| POST `/api/v1/users/{id}/mfa/reset` | SA, TA (own tenant) | `{reason (10–1000)}`; clears MFA, revokes the user's tokens; not for oneself |
| POST `/auth/logout` | any | revokes all of the caller's tokens |
| GET `/auth/oidc/config` | public | `{enabled, display_name}` |
| GET `/auth/oidc/login` → IdP → GET `/auth/oidc/callback` | browser | redirects to `/console/#sso_code=…` or `#sso_error=<id>` |
| POST `/auth/oidc/exchange` | public | `{code}` (one-time, 60 s) → `{access_token}` |
| POST `/auth/refresh` | any session | → `{access_token, session_expires_at}`; keeps sign-in time and MFA level; 401 after `SESSION_MAX_HOURS` |
| POST `/auth/change-password` | any | `{current_password,new_password(≥12)}`; revokes all tokens |
| POST `/auth/password-reset/request` | public | `{email}` → 202 always (503 without SMTP); emails a single-use link |
| POST `/auth/password-reset/confirm` | public | `{token,new_password(≥12)}` → 204; revokes all tokens; MFA unchanged |
| POST `/api/v1/users/{id}/password-reset` | SA, TA (own tenant) | `{reason (10–1000)}` → `{reset_url,expires_at}`; not for oneself |
| GET `/api/v1/audit-logs/verify` | SA | audit-log hash chain verification |
| POST `/api/v1/alert-destinations/{id}/test` | SA, TA | queue a labelled test alert (`type: honeyshield.test`, no detection event); 5/min per destination; result in `/deliveries` with `is_test: true` |
| GET `/api/v1/detection-events/export` | any | CSV, newest first, ≤ 50,000 rows; `since`, `until`, `severity`, `ip_address`, `decoy_id` (all recorded in the audit entry); token values replaced by `{token}`; formula-like cells prefixed with `'`; audited |
| POST `/api/v1/api-keys` | any (session, not a key) | `{name, scope: read\|write, expires_in_days 1–365}` → `{key_id, api_key (once), …}` |
| GET `/api/v1/api-keys` | any | own keys; TA: tenant's keys; SA: all |
| DELETE `/api/v1/api-keys/{key_id}` | owner, TA (tenant), SA | revoke |

**API keys** authenticate with `Authorization: Bearer hsk_….…` on every `/api/v1` endpoint the
owner's role allows, except `/api/v1/users*` and `/api/v1/api-keys*`. They are not accepted
by `/auth/*` or the live streams. Read keys allow GET/HEAD only.
| GET `/health`, `/api/v1/health` | – | liveness, no DB |
| GET `/ready`, `/api/v1/ready` | – | DB reachable, revision = head, (prod) runtime role least-privileged |
| GET/POST `/api/v1/tenants`, GET/DELETE `/api/v1/tenants/{slug}` | SA | new slugs: `^[a-z0-9](?:[a-z0-9-]*[a-z0-9])?$`, 2–63 chars (422 otherwise); `active_only=false` lists deactivated ones; DELETE deactivates (evidence kept) |
| GET/POST `/api/v1/users`, GET/PATCH `/api/v1/users/{id}`, POST `…/deactivate` | SA, TA (own tenant) | emails lower-cased; last active SA protected |
| GET/POST `/api/v1/projects`, GET/DELETE `/api/v1/projects/{domain}` | read: any; write: TA | domain = hostname, unique per tenant; DELETE deactivates |
| POST `/api/v1/projects/{domain}/honey-tokens/generate` | TA | `{token_type, generator_params?}` |
| GET `/api/v1/honey-tokens` | any | `project_domain`, `active_only`, `limit≤100`, `offset`; values masked for TU; each decoy carries `last_triggered_at` (null if it never fired; one index entry per decoy, 13.7 ms for 100 decoys at 10M events) |
| POST `/api/v1/honey-tokens` | TA | generates; `token_value` only for SA |
| POST `/api/v1/honey-tokens/revoke` / `/rotate` | TA | rotate regenerates value + artifact |
| GET `/api/v1/detection-events` | any | `limit≤1000`, `cursor` (keyset), `token_value`, `severity` (repeatable), `ip_address` (normalised), `since`/`until` (no offset = UTC), `decoy_id` (public id; another tenant's → 404 like an unknown one); each event carries `decoy_id`, `decoy_type`, `decoy_label`, `project_domain` (never the token value); paths masked for TU |
| GET `/api/v1/detection-events/{id}` | any | one event in scope, same fields as the list; another tenant's id → 404 like a missing one; paths masked for TU |
| POST `/api/v1/detection-events` | TA | manual event; `reason` (10-1000 chars) required; stored as MANUAL |
| GET `/api/v1/detection-events/statistics` | any | totals |
| GET `/api/v1/detection-events/activity` | any | `days` 1–90 (default 14) → `[{date, total, by_severity}]` per UTC day, oldest first, empty days included; trigger-maintained totals on PostgreSQL; 503 on the analytics time budget |
| GET `/api/v1/threats/summary`, `/top-attackers`, `/ip/{ip}`, `/timeline/{ip}` | any | heuristic scores (no ML) |
| GET/POST `/api/v1/projects/{domain}/integrations`, POST `…/{id}/revoke` | TA | secret returned once on create |
| GET/POST `/api/v1/alert-destinations`, DELETE `…/{id}`, GET `…/deliveries` | TA (SA with `tenant_slug`) | signing secret returned once; each delivery carries `created_at` (queued), `next_attempt_at`, `delivered_at` |
| GET `/api/v1/audit-logs` | TA (own tenant), SA | `event_type`, `before_id`, `limit≤500` |
| GET `/api/v1/evidence/verify` | TA, SA (`tenant_slug`) | chain verification result |
| GET `/api/v1/events/stream/sse` | any | Bearer header (or `?token=` for EventSource) |
| WS `/api/v1/events/stream/ws` | any | first message `{"type":"auth","token":…}` |
| GET `/metrics` | bearer `METRICS_TOKEN` | 404 when not configured or wrong token |
